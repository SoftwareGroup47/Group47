Privacy Policy

1. Data Collection

We only collect necessary user information, including:

  • Username
  • Password (encrypted storage)
  • User role (TA/MO)
  • TA profile (skills, grades)
  • CV files uploaded by TAs
  • Application records

2. Data Storage

All user data is stored in the local browser's localStorage and is not uploaded to any server. Data is stored only on the local device, ensuring data security and privacy protection.

3. Data Encryption

User passwords are encrypted and stored using the SHA-256 algorithm to ensure password security.

4. Data Usage

We only use collected data for the following purposes:

  • User authentication and authorization
  • Job application and management
  • TA workload analysis

5. Data Protection

We take the following measures to protect user data:

  • Encrypted password storage
  • Locally stored data isolation
  • User permission control

6. Data Deletion

Users can delete all locally stored data by clearing browser cache and localStorage.

7. Privacy Protection Commitment

We commit to:

  • Not collecting user data beyond what is necessary
  • Not sharing user data with any third party
  • Not using user data for any commercial purposes
  • Respecting users' privacy rights
